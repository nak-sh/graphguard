# GraphGuard 3–5 minute demo

## 0. Start

```bash
docker compose up --build -d
```

The Compose seed service loads the deterministic graph before the API starts. Open `http://localhost:3000`. Keep the **SYNTHETIC DATA** badge visible.

## 1. Show the connected-data investigation (about 60 seconds)

1. Select `ALERT-104` / `A-104`.
2. Run the investigation and point at the streamed tool cards: bounded neighborhood, device/IP checks, money paths, and cycle detection.
3. Show the score breakdown: time-respecting cycle, rapid pass-through, and non-hub shared device.
4. Explain that the cycle stays valid when the analyst starts from another ring member because temporal validity is rotation-invariant. The graph path is never reversed to make a result fit.

## 2. Show restraint (about 35 seconds)

1. Select `ALERT-D201` and run it.
2. Show the `NO_ACTION` disposition, household mitigator, evidence IDs, and the “lead, not proof” caveat.
3. Optionally show `D3-001`: the shared office device/IP is marked as a hub and does not become a 40-account escalation.

## 3. Show safe autonomy (about 75 seconds)

1. Return to T1 and preview the dry run. Point out that every target has a real FalkorDB `from` status and a proposed `to` status; there is no hard-coded `ACTIVE` value.
2. Explain that five affected accounts are proposed, but the incident is pending approval because the blast radius exceeds the auto-within-limits cap.
3. Approve the incident, execute one action, and show the mock gateway request log.
4. Click Verify. The graph status and gateway result must both be checked.
5. Re-submit the same idempotency key. It returns the original result without a second graph mutation.
6. Roll back, show the conflict-aware restore, and click Verify chain.

## 4. Close with measurement (about 30 seconds)

1. Open the Benchmark page and point out that the numbers are generated by `make benchmark`, not typed into the README.
2. Mention that SQL is allowed to be competitive at shallow/small points; the result is reported rather than assumed.
3. If time permits, open Red-team and show caught/missed variants with the knob suggestion.
